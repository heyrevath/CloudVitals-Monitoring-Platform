# CloudVitals Monitoring Platform

CloudVitals is a cloud monitoring and observability platform designed to provide real-time visibility into infrastructure health, container status, system performance, alerts, and logs. The platform combines monitoring, alerting, logging, and automated deployment into a single dashboard.

The project was built to simulate a production-style monitoring environment using modern DevOps tools and cloud infrastructure.

---

## Features

- Real-time system monitoring
- CPU, memory, disk, and network metrics
- Docker container monitoring
- Prometheus-based metrics collection
- Alertmanager integration for incident handling
- Centralized log management using Loki and Promtail
- Incident history tracking
- Automated deployment with GitHub Actions
- AWS EC2 hosting
- Dockerized application stack

## Monitoring Stack

### Prometheus

Prometheus collects infrastructure and application metrics from the backend service and evaluates alert rules.

### Alertmanager

Alertmanager processes alerts generated by Prometheus and manages alert routing and notification workflows.

### Loki

Loki stores and indexes application and infrastructure logs.

### Promtail

Promtail collects logs from running containers and forwards them to Loki.

---

## CI/CD Pipeline

CloudVitals uses GitHub Actions for continuous integration and automated deployment.

### Deployment Workflow

text Developer    ↓ Git Push    ↓ GitHub Actions    ↓ Build Validation    ↓ AWS EC2 Deployment    ↓ Docker Compose Rebuild    ↓ Updated CloudVitals Instance 

Every push to the main branch automatically triggers the deployment pipeline and updates the running application on AWS EC2.

---

## AWS Deployment

The platform is deployed on an AWS EC2 Ubuntu instance using Docker Compose.

Services deployed:

- React Frontend
- Node.js Backend
- Prometheus
- Alertmanager
- Loki
- Promtail

The deployment process is fully automated through GitHub Actions.
